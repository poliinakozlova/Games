# Платформер

Всього 3 рівні

## Як запустити

```
pip install pygame pydub audioop-lts
python main.py
```

## Керування

1. стрілки або A/D - ходити
2. пробіл або W - стрибок
3. Esc - пауза
4. R - почати заново

## Що є в грі

1. 3 життя, їх забирають вороги, шипи і падіння в яму
2. ворога можна розчавити, якщо стрибнути на нього зверху
3. монетка дає 10 очок, ворог 50
4. є рухомі платформи, які везуть гравця
5. зберігається рекорд

## Файли

1. main.py - запуск
2. game.py - головний цикл і логіка
3. player.py - гравець
4. sprites.py - вороги, платформи, монетки
5. levels.py - карти рівнів
6. menu.py - меню
7. sounds.py, make_sounds.py - звуки
8. assets.py - картинки
