# Платформер

Всього 3 рівні

## Як запустити

pip install pygame pydub audioop-lts
python main.py


## Керування

- стрілки або A/D — ходити
- пробіл або W — стрибок
- Esc — пауза
- R — почати заново

## Що є в грі

- 3 життя, їх забирають вороги, шипи і падіння в яму
- ворога можна розчавити, якщо стрибнути на нього зверху
- монетка дає 10 очок, ворог 50
- є рухомі платформи, які везуть гравця
- зберігається рекорд

## Файли

- main.py — запуск
- game.py — головний цикл і логіка
- player.py — гравець
- sprites.py — вороги, платформи, монетки
- levels.py — карти рівнів
- menu.py — меню
- sounds.py, make_sounds.py — звуки
- assets.py — картинки
